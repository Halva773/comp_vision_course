# Машинное зрение 

Код к семинарам по курсу "Машинное зрение".  
Тексты лекций - https://disk.yandex.ru/d/i5Z3MrWJx2p5Xw  

Зачет будет проходить в письменном виде, два вопроса по теории.  

Вопросы по теории:  
- История становления машинного зрения
- Задачи и проблемы машинного зрения
- Цветовые модели изображений, спектр  
- Модели изображений в пространстве, ошибки дискретизации и квантования
- Преобразование Фурье 1Д и 2Д
- Сжатие JPEG, webp  
- Теория вероятности в обработке изображений
- Выравнивание гистограмм
- Морфологические операции
- Аффинные операции
- Обнаружение углов и границ
- Линейный классификатор изображений
- SVM классификатор. Hinge loss
- Softmax классификатор. Cross entropy loss
- Регуляризация классификатора изображений
- Оптимизация параметров (обучение) линейного классификатора изображений
- Численный и аналитический метод взятия производной. 
- Продвинутые методы оптимизации (Momentum, RMS, Adam)
- Многослойные нелинейные классификаторы изображений
- Виды функций активации
- Механизм обратного распространения ошибки. Методы forward, backward
- Сверточный слой
- Слой сокращения размерности (pooling)
- Архитектуры LeNet, AlexNet
- Блоки Inception, свертка 1х1
- Блоки ResNet
- Семантическая сегментация
- Классификация с локализацией
- Детекция объектов
- Распознавание документов (OCR)
- Механизм Attention
- Блок трансформера
- Трансформеры для классификации
- Трансформеры для детекции объектов
